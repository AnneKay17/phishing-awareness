# AnneKay: phishing-awareness prank

A frontend-only React + Vite prank site. All account details are fictional (`src/data/mockAccountData.js`).
Nothing is collected, stored or sent.

    npm install
    npm run dev       # local dev server
    npm run build     # production build in dist/
    npm run preview   # serve the build locally

Deploy: push to GitHub, import the repo in Vercel (framework preset: Vite), deploy.
